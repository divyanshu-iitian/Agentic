# Roadmap

## Now

- keep the 8 GB RAM path fast and documented
- stream local model responses to the chat UI
- add explicit permission prompts for consequential actions
- measure startup time, idle memory, and first-token latency
- add reproducible state-based desktop task evaluations

## Next

- unify the chat and desktop-agent runtimes
- add signed skill metadata and trust levels
- persist chats locally with clear retention controls
- package Windows, Linux, and macOS builds
- add a hardware benchmark matrix for 8 GB, 16 GB, and GPU systems

## Later

- optional vision adapters with visible camera permissions
- plugin isolation and capability-scoped permissions
- reproducible release signing and update channels
- a reviewed community skill registry

Features move out of the roadmap only after documentation and repeatable tests
land with the implementation.
